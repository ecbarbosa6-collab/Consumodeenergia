##Sobre o Projeto
Este sistema foi desenvolvido em **Python** para calcular o consumo mensal de energia elétrica de aparelhos domésticos, permitindo uma melhor gestão de gasto energético.

#Fórmula para calculo
O cálculo utiliza a seguinte expressão matemática: $$consumoMensal = \frac{potencia \ times horasDia \times 30} {1000}$$
